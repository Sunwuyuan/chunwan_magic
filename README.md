# 魔术计算器 (Magic Calculator)

速通春晚魔术 - 一个支持魔术模式的计算器

## 功能介绍

这是一个特殊的计算器应用，外观和功能与普通计算器完全相同，但具有独特的"魔术模式"功能。

### 普通模式
- 标准的计算器功能
- 支持加、减、乘、除运算
- 支持小数点输入
- 支持清除和退格功能

### 魔术模式
在魔术模式下，计算器会执行一个特殊的"魔术":

1. **设置目标数字**: 通过日期时间设置目标数字，例如 2026年02月06日22时33分33秒 会生成 `20260206223333`
2. **设置触发数字**: 输入特定的触发数字（默认: 888）来激活魔术模式
3. **日期格式选项**: 可以选择是否对日期进行补零（例如：`20260206` vs `202626`）
4. **设置操作次数**: 指定通过多少次加法运算达到目标数字（2-10次，默认5次）
5. **魔术运算**: 
   - 当用户输入触发数字后，魔术模式自动激活（无UI提示）
   - 用户按下任意数字键，每次显示一个数字（逐位显示）
   - 这些数字经过精心计算，确保经过指定次数的加法后，最终结果正好等于目标数字
   - 按下 + 号后计算当前累加值
   - 重复操作直到达到目标值

## 使用说明

### 激活魔术模式

1. **打开设置**: 点击右上角的齿轮图标
2. **启用魔术模式**: 打开"启用魔术模式"开关
3. **配置目标日期时间**: 
   - 输入年、月、日、时、分、秒
   - 选择是否补零
   - 设置触发数字（默认: 888）
   - 设置操作次数（默认5次）
4. **确定设置**: 点击"确定"按钮

### 执行魔术

1. 在计算器上输入触发数字（如: 888）
2. 魔术模式自动激活（无可见提示）
3. 按下 + 号准备第一次操作
4. **按任意数字键** - 每次按键显示下一位数字
5. 继续按数字键直到完整数字显示完毕
6. 按 + 号计算累加值
7. 重复步骤 4-6，完成指定次数的操作
8. 按 = 号查看最终结果（目标数字）

### 重要特性

- **逐位显示**: 魔术数字不是一次性显示，而是每按一个按钮显示一位
- **无UI提示**: 魔术模式激活后没有任何视觉提示，保持计算器外观完全正常
- **智能阻止**: 达到操作次数或目标值后自动阻止进一步输入
- **剩余值显示**: 超过预设操作次数后，显示到达目标所需的剩余值

## 开发说明

### 核心算法

魔术模式的核心是生成一组随机数，使其和等于目标数字：

1. 将目标数字分配给 N 个随机数
2. 确保每个随机数都是正数
3. 所有随机数的总和等于目标数字
4. 随机打乱这些数字的顺序

### 逐位显示机制

```javascript
// 将魔术数字转换为数字数组
magicCurrentNumberDigits.value = String(magicNumbers[index]).split('')

// 每次按键显示一位
const digit = magicCurrentNumberDigits.value[magicCurrentDigitIndex.value]
currentValue.value += digit
magicCurrentDigitIndex.value++
```

### 状态管理

- 使用 Vue 3 Composition API
- 通过 props 在组件间传递魔术模式状态
- 使用 ref 和 computed 管理响应式数据
- 跟踪当前数字的位数索引
