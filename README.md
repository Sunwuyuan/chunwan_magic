# 魔术计算器 (Magic Calculator)

速通春晚魔术 - 一个支持魔术模式的计算器

## 功能介绍

这是一个特殊的计算器应用，外观和功能与普通计算器完全相同，但具有独特的"魔术模式"功能。

### 普通模式
- 标准的计算器功能
- 支持加、减、乘、除运算
- 支持小数点输入
- 支持清除和退格功能

### 魔术模式
在魔术模式下，计算器会执行一个特殊的"魔术":

1. **设置目标数字**: 通过日期时间设置目标数字，例如 2026年02月06日22时33分33秒 会生成 `20260206223333`
2. **日期格式选项**: 可以选择是否对日期进行补零（例如：`20260206` vs `202626`）
3. **设置操作次数**: 指定通过多少次加法运算达到目标数字（2-10次）
4. **魔术运算**: 
   - 当用户输入任何数字时，计算器会自动替换为预先生成的随机数
   - 这些随机数经过精心计算，确保经过指定次数的加法后，最终结果正好等于目标数字
   - 用户看似随机输入的数字，最终会神奇地得到预设的日期时间数字

## 使用说明

1. **打开设置**: 点击右上角的齿轮图标
2. **启用魔术模式**: 打开"启用魔术模式"开关
3. **配置目标日期时间**: 
   - 输入年、月、日、时、分、秒
   - 选择是否补零
   - 设置操作次数（建议5次）
4. **确定设置**: 点击"确定"按钮
5. **执行魔术**: 
   - 点击任意数字按钮
   - 点击 + 号
   - 重复上述步骤，直到完成指定次数的操作
   - 点击 = 号查看魔术结果

## 开发说明

### 核心算法

魔术模式的核心是生成一组随机数，使其和等于目标数字：

1. 将目标数字分配给 N 个随机数
2. 确保每个随机数都是正数
3. 所有随机数的总和等于目标数字
4. 随机打乱这些数字的顺序

### 状态管理

- 使用 Vue 3 Composition API
- 通过 props 在组件间传递魔术模式状态
- 使用 ref 和 computed 管理响应式数据
